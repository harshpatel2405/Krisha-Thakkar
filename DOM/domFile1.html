Create Element | Append | AppendChild | Remove | RemoveChild

DOM Methods Used

1. createElement()
Creates a new HTML element using JavaScript.

2. appendChild()
Adds a single Node as the last child of an element.

3. append()
Adds text or one or more Nodes at the end of an element.

4. querySelector()
Selects the first HTML element that matches a CSS selector.

5. removeChild()
Removes a specific child element from its parent.

6. remove()
Removes the selected element itself from the DOM.
