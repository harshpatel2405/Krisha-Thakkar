DOM Methods - Definitions

1. prepend()
Adds new content at the beginning of the selected element. The new content becomes the first child.

2. before()
Adds new content before the selected element. The new element becomes a sibling of the selected element.

3. after()
Adds new content after the selected element. The new element becomes a sibling of the selected element.

4. insertBefore()
Adds a new element before a specific child element inside a parent element.

5. replaceChild()
Replaces an existing child element with a new element.

6. createElement()
Creates a new HTML element using JavaScript.

7. getElementById()
Selects an HTML element using its ID.

8. innerText
Gets or changes the visible text inside an HTML element.

9. innerHTML
Gets or changes the HTML content inside an element.

10. setAttribute()
Adds or changes an attribute of an HTML element.
